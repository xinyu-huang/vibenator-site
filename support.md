# Gershwin Support

**Contact:** [xinyu.huang@gmail.com](mailto:xinyu.huang@gmail.com). Please include
your macOS version and Gershwin's version (Gershwin ▸ About Gershwin).

## Requirements

- A Mac with Apple silicon, running macOS 15 Sequoia or later.
- The Search assistant's natural-language answers use Apple Intelligence, which
  needs macOS 26 and Apple Intelligence turned on. Without it, Search still works
  with keywords.

## Common questions

**Getting started.**
Gershwin opens with no library. Choose File ▸ **New Library…** to create one (or
**Open Library…** for an existing one), then add your music folders in File ▸
**Manage Library Sources…**.

**Gershwin says it has no permission to read a folder.**
The Mac App Store version can only read folders you have chosen yourself.
Click **Grant Access…** when Gershwin asks and confirm each folder, or add it
again in File ▸ **Manage Library Sources…**. Gershwin remembers each folder once you
have confirmed it.

**My UPnP/DLNA renderer doesn't appear.**
macOS asks for permission the first time Gershwin looks on your local network.
If you declined, turn it back on in System Settings ▸ Privacy & Security ▸ Local
Network, then restart Gershwin. The renderer and your Mac must be on the same
network.

**Some albums stay unmatched.**
Not every release is in MusicBrainz, and Gershwin would rather leave an album
unmatched than attach it to the wrong release. You can pick a release by hand in
the **Inspect/Fine-tune Enrichments** window.

**Does Gershwin change my files?**
No. Gershwin reads your music files and never modifies, moves or deletes them.
What it learns is kept in its own library, and excluding a duplicate only hides
it from the library.
